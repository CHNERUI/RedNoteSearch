## 区域与字段

- 当前 `GET /scenarios` 的 `scene` 是 `seeding/review/tutorial/launch/promotion/story` 固定枚举；不存在品牌创作类型 CRUD、使用数、类型名称快照或动态 type_id。
- 列表提案字段：稳定 id、brand_id、name、enabled、task_usage_count、template_usage_count、can_delete（待 A 定稿）；名称建议去首尾空白后 1–40 码点，同品牌重名反馈在字段旁。限制及大小写/空白归一规则尚不是现有契约。
- 新增只创建类型，不偷偷创建模板；空类型可以暂时没有可用模板，生成页应说明并保持原有必选模板校验。
- 改名保持稳定 id；图中提出历史任务保留创建时名称快照，新任务和筛选展示最新名称。旧任务存储方式和是否有快照需 A 确认，不能改写历史内容。
- 停用停止新任务使用；历史任务及已生成内容可读。对启用模板、待生成任务的影响必须由服务端依赖检查明确返回；弹窗依赖信息加载完成前不能确认。图中存在模板依赖，停用按钮禁用并显示“先处理关联模板”；依赖无阻塞时才提供确认停用。
- 不能删除已被任务引用的类型；按钮不可用且提供可读原因“已有 N 个任务使用，不能删除，请改为停用”。未引用不意味着自动可删，其他模板引用也需服务端校验。
- 场景模板按启用类型筛选；管理者可通过显式状态筛选查看停用项。过滤后无模板与全品牌无模板分别提示，不把两种空状态当成请求错误。

## 交互

1. 搜索、状态与类型筛选保留在当前品牌；切品牌清除旧筛选和选中记录。列表按名称/状态排序规则由契约明确，不使用画稿顺序作业务默认。
2. 新增/改名在弹窗中填写，字段错误不关闭；提交中禁用重复保存，取消不保存；有修改时关闭先提示。
3. 停用/启用二次确认，显示类型名、影响数量与依赖；并发被引用时保留页面并显示服务端 409 原因，不硬删或自动重试删除。
4. 图中被引用行不提供删除按钮；另用提示解释不可删除。未引用的“删除”也须单独确认且由服务端检查引用；本稿不决定软删除或永久删除。
5. 弹窗焦点进入标题/首字段、Tab 循环、Escape 关闭（提交中不关闭），关闭后焦点回到触发按钮。禁用原因不用仅 hover 的提示，键盘用户也能读到。
6. 权限不足时列表可读与无权访问分开：editor 隐去管理入口，直接请求管理操作显示 403；非品牌成员遵循服务端不泄露策略。错误保留 request_id 并允许适当重试。

## 与契约或约束不一致的地方

现有场景枚举不能靠前端改显示文案实现自定义类型。需 A 另行定义类型实体/权限、稳定 ID、CRUD/停用、重名、引用计数与不可删错误；迁移旧六类及模板归属、生成和评测输入兼容、任务名称快照、并发校验亦待确认。模板的 `scene` 到动态类型的映射没有擅自定稿。本 PR 只交设计 PNG + spec，不改后端、客户端、导航、token 或页面代码。
